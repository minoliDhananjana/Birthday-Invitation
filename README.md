# 🎀 MION's First Birthday Invitation 🧚‍♀️

A cute and magical digital birthday invitation website created to celebrate **MION's First Birthday**.

The invitation is designed with a soft fairy-tale theme using pink colors, animations, music, countdowns, event details, and interactive elements to create a memorable first-birthday experience for guests.

---

##  Features

-  Magical first birthday invitation design
-  Fairy-themed baby welcome section
-  Animated birthday elements
-  Background fairy music
-  Automatic music playback after opening the invitation
-  Special baby voice/message section
-  Live countdown to the birthday
-  Event date and time details
-  Venue information
-  RSVP section
-  Floating stars and magical animations
-  Mobile-friendly responsive design
-  Smooth animations using Framer Motion
